# Simulation methods and limitations

Input/output assumption: SDR sRGB/BT.709 primaries. Decode with the piecewise sRGB
transfer (`c/12.92` below 0.04045; power 2.4 above). Transform in linear light.
Apply separate artistic saturation, exposure and contrast. Clip out-of-gamut linear
output to [0,1], then encode using the inverse transfer. Custom matrices are row-major.

## Sources

- Machado, Oliveira, Fernandes (2009), *A Physiologically-based Model for Simulation
  of Color Vision Deficiency*, IEEE TVCG 15(6), 1291–1298.
  [Authors and tables](https://www.inf.ufrgs.br/~oliveira/pubs_files/CVD_Simulation/CVD_Simulation.html).
  Coefficients transcribed from the MIT-licensed [Colorspacious 1.1.2 table](https://github.com/njsmith/colorspacious/blob/v1.1.2/colorspacious/cvd.py).
  The authors' server timed out during this session; the table mirror and citation
  were available. All 11 severity samples per deficiency are retained.
- Brettel, Viénot, Mollon (1997), *Computerized simulation of color appearance for
  dichromats*, JOSA A 14(10), 2647–2655.
  [Paper](https://vision.psychol.cam.ac.uk/jdmollon/papers/Dichromatsimulation.pdf).
- [DaltonLens method analysis](https://daltonlens.org/understanding-cvd-simulation/)
  and [MIT implementation](https://github.com/DaltonLens/DaltonLens-Python):
  Smith-Pokorny 1975 LMS, Judd-Vos-adjusted sRGB primary matrix, 475/575 nm
  protan/deutan and 485/660 nm tritan spectral anchors. Use display white as neutral.
- [W3C CSS Color 4 sRGB conversion](https://www.w3.org/TR/css-color-4/#color-conversion-code).

## Preset interpretation

| Presets | Recommended transform | Evidence boundary |
|---|---|---|
| Protanopia/protanomaly, deuteranopia/deuteranomaly | Machado table interpolation | Research model; opia endpoint at 100%; not an individual perceptual match |
| Tritanopia | Brettel two-plane LMS projection | Research-based dichromacy with white-neutral sRGB adaptation |
| Tritanomaly | Blend with Brettel endpoint | Approximation, not a validated tritan anomaly model |
| Achromatopsia, achromatomaly | BT.709 luminance grayscale / blend | Approximation; no rod response, photophobia, acuity or spatial model |
| Blue-cone monochromacy | S-cone weighted neutral grayscale | Experimental; rods/adaptation absent |
| Cone monochromacy | Selected L/M/S weighted neutral grayscale | Experimental |
| Acquired red-green / blue-yellow | Deutan / tritan appearance proxies | Experimental; cannot model heterogeneous causes, progression, fields |
| Generalized desaturation | Linear luminance blend | Artistic |
| Custom LMS | inverse(LMS) * diag(gains) * LMS | Experimental response adjustment, not missing-cone physiology |
| Custom matrix | User matrix in linear RGB | Artistic |

Machado may be selected for tritan, but has known limitations; recommended mode uses
Brettel. Brettel at partial severity blends identity and dichromat projection; it is
not presented as a physiological anomalous-trichromacy model. L/M/S gain controls are
enabled only for the custom LMS preset. Common deficits are never simulated by simply
zeroing RGB channels. Severity 0 is identity before artistic adjustments.

CPU and HLSL use identical row matrices and branch separator. The tests validate sRGB
known values, Machado endpoint values/interpolation, projection invariants, finite
gamut and CPU/GPU parity. Numerical agreement is not clinical validation.

96 independent vectors are generated by pinned DaltonLens revision
`3cba5e6a7c8f0e8199c8f83f1afb58eb6dab7a3d` (see tools/generate_reference.py).
The older PyPI 0.1.5 color model differs from this revision's Judd-Vos adaptation.
The reference's Machado fractional interpolation alpha omits a factor of ten;
external fixtures therefore use exact Machado table severities and Brettel outputs.
CVS interpolation is separately checked at midpoints of adjacent published matrices.

Monitor calibration, ICC transforms, HDR, ambient adaptation, age, spatial acuity,
individual cone spectra and viewing context are outside the implemented model.
